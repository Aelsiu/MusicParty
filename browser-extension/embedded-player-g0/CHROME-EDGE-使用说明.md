# Chrome / Edge 扩展安装与验收

“MirthParty 内嵌解析器”的版本统一来自项目根目录 `VERSION`，Chrome 和 Edge 安装同一解压目录。媒体由扩展 iframe 直接访问原有 CDN，网站访问权限由你输入地址后确认授权。

## 入口条件

- 使用桌面 Chrome 或 Microsoft Edge。当前隔离测试版本为 Chrome 155.0.8059.40、Edge 155.0.4283.45。
- 网页须包含本轮解析器连接支持，并使用 HTTP 或 HTTPS。填写你实际访问的 MirthParty 网站地址；扩展只在启用地址对应的协议、主机和端口上生效。
- Windows 启动器 WebView2 无法加载本扩展。使用扩展时，请在桌面 Chrome / Edge 打开自己的 MirthParty 网站；可配置本机或其他部署地址。

## 安装或更新

1. 将 `MirthParty-parse-版本-提交短号.zip` 解压到固定位置，保留同名扩展目录；不要直接选择 ZIP。目录中的 `build-metadata.js` 记录完整版本和构建基线提交号。
2. Chrome 地址栏打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 打开“开发者模式”或“开发人员模式”，点击“加载已解压的扩展程序”或“加载解压缩的扩展”。
4. 选择包含 `manifest.json` 的目录，确认出现“MirthParty 内嵌解析器”，数字版本与该包的全局版本一致（例如 2.1.0）。完整 `版本-短号` 写在 `manifest.json` 的 `version_name`；预发布版本的数字部分用于浏览器版本比较。更新时，将新包文件复制到原先加载的固定目录，在管理页点击扩展的重新加载按钮；原包保留备份。
5. 打开工具栏扩展菜单中的本扩展。在“MirthParty 网站地址”填写完整 HTTP(S) 地址，打开同排“启用解析器”开关，并允许浏览器请求的网站访问权限。可粘贴网站或房间链接，保存时只保留协议、主机和端口；首次没有默认地址，后续会记忆已配置的地址。
6. 等待状态显示“已在 [你的地址] 上启用解析器”，此时地址锁定。点击状态中的地址打开网站，刷新已有网页，再登录 / 进入房间。浏览器重启后默认停用，记忆地址仍保留，需再次启用。

更换地址前先关闭开关，等待“未启用解析器”且地址解锁，再修改并重新启用。操作中的开关暂时不可点击；若显示错误，按提示检查地址或权限并重试。没有收到实际确认时不会显示启用成功；无法确认状态时，请重新打开扩展。

Chrome 正式版已移除通过 `--load-extension` 命令行安装的能力。请使用以上管理页步骤，参考 [Chrome 官方安装说明](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world)。

## 使用

1. 房间切换到 VIDEO 并开始视频。网页播放失败、提示 DASH 音轨不可用时，可点击错误通知上的“使用扩展”。
2. 也可点击视频控制条最左侧、刷新视频源左边的切换按钮，主动切换到扩展播放。再次点击该按钮可回到网页播放。
3. 扩展播放保留网页统一进度条、音量、倍速、弹幕及全屏操作；画面不再出现第二套原生控制条或常驻扩展提示。双击画面切换全屏。
4. 自动播放被阻止时，点击网页提示中的恢复播放操作，再检查声音和画面是否推进。握手成功不等于媒体已播放。
5. 关闭扩展弹窗中的开关会清理注册脚本、旧播放器连接和规则；等待“未启用解析器”确认后，地址会重新解锁。浏览器管理页撤销网站访问权限也会停用解析器。

## 验收

检查横屏 / 竖屏画面无滚动条，鼠标经过画面时只有网页控制条，2 小时以上的视频时间完整显示 `00:00:00`。检查切换、双击全屏、最小化后恢复、音量、倍速、画质和房间进度跳转。

多人验收使用至少两个独立浏览器配置，并区分成员名称。建议三个成员安装并启用扩展，另两个成员不安装；未安装端选择扩展失败应仅影响本端，不让房间等待。检查安装者实际声画和进度一致，房间 seek、刷新源、切集、退房重进及停用扩展后无旧状态回流。某个已正常播放的成员缓冲时，既有全员等待截止时间应固定，超时后其他成员继续播放。

记录网页版本 / 提交号、扩展版本、浏览器版本、人数、BV 或 EP、触发操作和实际结果。声画问题注明有画无声、有声无画、不同步或卡顿。不要发送 Cookie、许可值或带签名的 CDN 链接。

真实人工声画、长时间自然签名到期续期、云端部署及实际多设备网络仍需验收；自动解码和本地房间验证不能替代这些结果。
